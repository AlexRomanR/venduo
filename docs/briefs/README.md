# Briefs

Lo que se pidió con `/idea`, ya aclarado: un archivo por tarea mediana o grande,
`AAAA-MM-DD-nombre-corto.md`. Lo escribe la entrevista de la skill `de-idea-a-pantalla`
antes de investigar, planear o escribir código, y es lo que reciben el analista, el
diseñador y el verificador.

Sirve también después: cuando alguien pregunta por qué una pantalla es como es, el brief
dice qué se quería resolver, para quién y qué quedó fuera.
